# Раунд 1: независимые позиции

Это сжатая карта четырёх независимых предложений. Она используется как общий вход для раунда взаимной критики.

## 1. Архитектор — «РАЗЛОМ-4»

- Три направленных раунда атак, чтобы каждое исходное предложение было атаковано всеми остальными.
- Замороженные графы исходных механизмов защищают от переписывания истории.
- Новый кандидат обязан использовать преобразованный материал минимум трёх ролей.
- Новизна: новый причинный мост, графовое отличие от каждого родителя и абляция моста, возвращающая минимум два противоречия.
- Отбор без пятого LLM: жёсткие фильтры, затем максимизация худшего ролевого балла.
- Риск: высокая стоимость, спорный порог графового расстояния, сложность извлечения причинных графов.

## 2. Скептик — «4Н»

- Нельзя гарантировать создание нового; допустим честный результат «новизна не подтверждена».
- Роли должны производить разные проверяемые артефакты, а не играть характеры.
- Отдельные ворота: валидность, полезность, доказательства и ограниченная новизна относительно заданного корпуса аналогов.
- Обоснованное veto возможно только при формальном противоречии, контрпримере, нарушении ограничения, аналоге или непроверяемом тезисе.
- Минимум для принятия: новый механизм, toy-тест и измеримое преимущество над baseline.
- Риск: генеалогический поиск может быть дорогим или недоступным; ротация ролей размывает специализацию.

## 3. Упрощатель — двухраундовый «РАЗЛОМ-4»

- Ровно восемь LLM-вызовов: четыре слепых предложения и четыре одновременные атаки-мутации.
- Фиксированный кольцевой граф атак.
- Каждый агент обязан украсть одно свойство противника, отбросить собственную предпосылку и создать ровно один новый причинный оператор.
- Машинно проверяемый JSON и сертификат новизны.
- Детерминированный взвешенный score; один точечный ремонт, но не бесконечный спор.
- Риск: один критик на предложение оставляет слепые зоны; взвешенное среднее может скрыть смертельный недостаток.

## 4. Охотник за отказами — «КВАРТЕТ-Δ»

- Два встречных цикла атак; атака обязана иметь контрпример, различающий тест и условие уступки.
- Синтез ломает общую скрытую предпосылку тезиса и антитезиса.
- Новый кандидат отвечает минимум на три ограничения разных ролей, содержит эксперимент и rollback.
- Анонимная «гильотина»: побеждает максимальный минимальный внешний балл; veto действительно только с kill-test.
- Процесс сам проходит kill-tests на псевдоразнообразие, сговор, доминирование, театральный спор, усреднение, непроверяемость и зацикливание.
- Риск: эвристические пороги доминирования и новизны; разные seed не гарантируют разный взгляд одной модели.

## Общие точки без преждевременного согласия

Все позиции независимо требуют:

1. слепые исходные предложения;
2. структурированные атаки с контрпримером;
3. запрет простого усреднения;
4. новый причинный механизм, а не новые слова;
5. проверяемый тест и возможность честного провала;
6. отсутствие пятого рассуждающего судьи.

Их спор остаётся открытым по четырём вопросам: сколько атак достаточно; нужен ли внешний корпус аналогов; использовать ли средний или худший балл; насколько формально представлять причинный механизм.
