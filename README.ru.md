# РАЗЛОМ-4

**РАЗЛОМ-4 — проверяемый протокол конфликта четырёх субагентов.** Его цель — не
усреднить мнения и не передать решение пятой модели, а преобразовать
противоречие в новую причинную мутацию с тестом или честный сертификат провала.

## Основной цикл

```text
контракт задачи
  → 4 слепых предложения
  → полный перекрёстный конфликт + 4 мутации
  → анонимная проверка чужих кандидатов
  → жёсткие ворота → maximin → результат или сертификат провала
```

Четыре роли имеют несовместимые обязанности:

- **Архитектор** максимизирует эффект и раскрывает цену сложности.
- **Скептик** минимизирует недоказанные предпосылки и даёт контрпример.
- **Упрощатель** удаляет компоненты и называет потерянную функцию.
- **Аварийщик** оптимизирует худший случай, rollback и остаточный риск.

Автор мутации обязан отказаться от собственной frozen assumption, сохранить
чужой инвариант и использовать давление минимум трёх ролей. Кандидат должен
содержать новый causal operator, prediction, falsifier, ablation, experiment и
rollback. Автор не проверяет себя. Победителя выбирают детерминированные ворота
и maximin внешних оценок.

`NO_VALID_MUTATION` — корректный итог. Метод сам устанавливает максимум
`panel_novel`, а не мировую новизну.

## Полный режим KUDS → РАЗЛОМ-4

В версии 0.2 перед конфликтом можно включить генератор KUDS:

```text
контракт задачи
  → KUDS: карта банальных решений + 12 дивергентных семян
  → детерминированный отбор 4 разных семян
  → 4 слепых ролевых коммита
  → конфликт, причинная мутация и внешняя проверка
  → жёсткие ворота + maximin
  → dossier идеи или сертификат провала
```

KUDS расширяет пространство поиска, а РАЗЛОМ-4 атакует и дорабатывает идеи.
Полный запуск использует 13 модельных вызовов: один вызов KUDS и исходные три
раунда по четыре. В артефакте сохраняются весь пул, баллы отбора семян, полная
сессия, детерминированный результат и карточка победителя. Незапущенные тесты
честно сохраняют статус `NOVELTY_UNCONFIRMED`.

## Запуск

```bash
python3 razlom4.py validate example_session.json
python3 razlom4.py select example_session.json
python3 -m unittest discover -v
```

После локальной установки объединённый режим запускается через OpenRouter:

```bash
export OPENROUTER_API_KEY="..."
razlom4-full full_pipeline_task.json \
  --output runs/support-routing.json \
  --model z-ai/glm-5.1
```

Для полностью воспроизводимого запуска без API можно передать заранее
сохраненный список ответов через `--replay responses.json`.

Готовый ноутбук для Google Colab: [`RAZLOM4_KUDS_GLM51_Colab.ipynb`](RAZLOM4_KUDS_GLM51_Colab.ipynb).

В репозитории также есть слепой benchmark harness для сравнения single agent,
best-of-4, обычного debate, РАЗЛОМ-4 без ролей и полного протокола при одинаковом
токен-бюджете.

Текущий трёхзадачный банк — только smoke-test инфраструктуры. Первый blind case
study завершился `NO_VALID_MUTATION`; single-agent control получил тот же
финальный verdict. Поэтому превосходство метода пока не доказано.
